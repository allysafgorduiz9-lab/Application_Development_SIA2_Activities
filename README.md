The repository serves as a collection of all completed activities, exercises, and projects developed throughout the semester. Each activity is organized according to its respective subject for easy navigation, documentation, and evaluation.
Subjects Included

Application Development and Emerging Technologies
This subject consists of the following activities/projects:
Activity 1 – Video Presentation: Artificial Intelligence
This group activity is a video presentation about Artificial Intelligence (AI) as part of the Emerging Technologies Exploration. The presentation explains AI in simple terms, discusses its applications in healthcare, education, and transportation, highlights its advantages and disadvantages, analyzes its impact on society, and presents predictions on how AI may evolve over the next 5–10 years. The activity demonstrates collaboration and understanding of emerging technologies.
Activity 2 – UML Diagram Design Project
This individual activity involves designing the Simeon Brewers Coffee: Web-Based Ordering and Administration System using UML principles. The system allows customers to browse and order coffee products online while enabling administrators to manage products, orders, and transactions. The project identifies the actors and major system functions and presents an Activity Diagram to illustrate the workflow and interactions within the system.


System Integration and Architecture 2 (SIA 2)
This subject consists of the following activities/projects:
Activity 1 – UML-Based Title Proposal
This activity presents the Simeon Brewers Coffee: Web-Based Ordering and Administration System as a proposed project based on UML concepts. It includes the project title, system purpose and scope, identification of users and system components, and a preliminary UML diagram that demonstrates planning, system analysis, and software design principles.

Activity 2 – SK Event List
SK Event List is a Laravel-based web application that displays and manages Sangguniang Kabataan (SK) events. Users can browse a list of events, view detailed information about each event, and navigate back to the main event list through a simple and organized interface. Access: http://127.0.0.1:8000/items

Activity 3 – Youth Suggestion Box
The Youth Suggestion Box is a Laravel CRUD application that allows users to submit, view, update, and delete youth suggestions. The project demonstrates database configuration, migrations, routing, controllers, Blade templates, and CRUD operations while providing an organized platform for collecting youth feedback. Access: http://127.0.0.1:8000/suggestions

Activity 4 – Recipe Sharing Form
The Recipe Sharing Form is a Laravel-based web application that enables users to submit and share recipes by providing details such as the recipe name, ingredients, cooking time, country of origin, and cooking instructions. The system demonstrates form handling, routing, controller logic, input validation, and error handling using Blade templates. Access:http://127.0.0.1:8000/form

Activity 5 – Youth Portal
The Youth Portal is a Laravel web application that implements user authentication with role-based access for Admin and User accounts using Laravel Breeze. It includes an internal API and integrates an external JSON API to display unemployment rates in the Philippines across different years. The project demonstrates authentication, API development, API integration, and dashboard implementation that combines user information, internal data, and external statistics in one system. Access:http://127.0.0.1:8000/dashboard
